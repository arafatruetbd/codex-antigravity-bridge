# Contributing

Issues and pull requests are welcome.

1. Fork the repository and make a focused change.
2. Keep Antigravity invocation **explicit opt-in only**; never add automatic
   delegation or permission-bypass defaults.
3. Run `npm test` and `npm run check`.
4. Do not include real run logs, credentials, or user-specific paths.
5. Describe the change and its safety implications in your pull request.
